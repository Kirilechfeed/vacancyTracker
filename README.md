# Vacancy Tracker

Полнофункциональное веб-приложение для отслеживания откликов на вакансии. Помогает визуально отслеживать статистику по вакансиям, на которые вы откликались.

## 🎯 Возможности

- ✅ **Добавление вакансий** — форма с автоопределением сайта по URL
- ✅ **Управление статусами** — Applied, Viewed, Interview, Offer, Rejected
- ✅ **Фильтрация** — по статусу, по источнику, по дате
- ✅ **Аналитика** — графики активности, распределения статусов, источников вакансий
- ✅ **Темизация** — светлая и тёмная тема
- ✅ **Mobile Responsive** — адаптивный дизайн
- ✅ **Local Storage** — сохранение данных в браузере (готово к интеграции Supabase)

## 🛠 Технический стек

- **Frontend:** React 18 + TypeScript
- **Styling:** Tailwind CSS
- **Маршрутизация:** React Router v6
- **Графики:** Recharts
- **Иконки:** Lucide React
- **Сборка:** Vite
- **Хранение:** Local Storage (Supabase ready)

## 🚀 Установка и запуск

### 1. Установить зависимости

```bash
npm install
```

### 2. Запустить dev сервер

```bash
npm run dev
```

Приложение откроется на `http://localhost:5173`

### 3. Сборка для продакшена

```bash
npm run build
```

## 📊 Функциональность

### Страница "Вакансии"

- Просмотр всех добавленных вакансий в виде карточек
- Фильтрация по статусу и источнику
- Быстрое изменение статуса
- Удаление записей
- Просмотр полной информации (комментарии, теги)

### Страница "Добавить"

- Форма для добавления новой вакансии
- Автоматическое определение источника по URL (LinkedIn, Indeed, etc.)
- Поддержка комментариев и тегов
- Валидация URL

### Страница "Аналитика"

- 📊 Количество откликов по дням (line chart)
- 📊 Распределение статусов (pie chart)
- 📊 Источники вакансий (bar chart)
- 🔥 Воронка: Applied → Offer
- 📈 Ключевые метрики (всего откликов, интервью, предложения и т.д.)
